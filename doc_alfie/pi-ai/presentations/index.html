01

The package makes heterogeneity a boundary concern

A

Normalize the agent surface

One serializable Context, one message model, one tool schema, one event protocol, and one usage shape across providers.

B

Separate ownership from protocol

A provider owns catalog and auth. Reusable API adapters own wire formats such as OpenAI Responses or Anthropic Messages.

C

Pay only for what is used

The root entry is side-effect free. Provider factories are independent; SDK-backed API modules load on the first request.

D

Preserve provider truth

Reasoning, cache usage, raw stop reasons, response IDs, compatibility flags, and errors survive normalization.

The abstraction removes integration repetition without pretending every provider behaves identically.

One object, two consumption modes

Use for await for live UI updates, then call result() for the final AssistantMessage. complete() is exactly this final-result path.

Failure stays in protocol

Async setup, lazy-import, auth, transport, and abort failures terminate with an error event and a final message. Consumers do not lose partial output semantics.

The event grammar is the stable integration point for terminals, agents, telemetry, and tests.

08

Authentication is provider-owned and concurrency-safe

Resolution precedence

1Explicit per-request API key
2Stored provider credential
3Environment or ambient auth

A stored credential owns the provider. Failed OAuth refresh never silently falls back to an environment key.

CredentialStore

Injectable persistence with read, metadata-only list, serialized modify, and delete. The default is in-memory.

OAuth refresh

Refresh uses double-checked locking inside modify, a five-minute validity window, and a 15-second refresh timeout.

AuthContext

Abstracts environment and file checks so Node, browser bundles, tests, and host applications can supply different ambient sources.

ARCHITECTURAL TAKEAWAY

Stable above.
Adaptable below.

Applications program against context, tools, streams, usage, and stop reasons.

Providers own identity, model availability, authentication, and API selection.

Adapters absorb protocol and transport differences while preserving important provider details.

Generated metadata keeps the fast synchronous runtime path current and strongly typed.

This separation is what lets pi-ai grow provider coverage without multiplying agent-side complexity.
